# ctx home

ctx is a context navigation framework for AI-assisted creative work.
It helps you keep orientation across sessions, models, and interruptions.

## Setup

1. Put this folder on your `PATH`.
2. Open PowerShell 7+.
3. Run:

```powershell
ctx chart
```

If you're inside a project, register it first:

```powershell
ctx register
```

## Philosophy

- **Your context survives between sessions.**
- **Chart is the heartbeat.** It gives a compact orientation snapshot.
- **Dock is the checkpoint.** It records where to resume next.
- **Commands grow through use.** If a command is missing, add it or grow it from a kit.

## Why use ctx at home?

ctx is designed for people working with:

- local models for fast, cheap iteration
- cloud models for deeper synthesis
- personal writing, design, research, planning, and reflective work

The framework helps manage handoff between small and large models so the next session can re-enter the work quickly.

## Rate-limit aware by design

ctx is intentionally built around compact orientation.
That makes it useful when:

- API budgets are limited
- rate limits slow down long conversations
- you want a small local model to prepare context before escalating to a larger one

## Included ideas

This home edition keeps:

- the **vessel / harbor** model
- the **descent** from unknown to situated work
- the **chart / dock** rhythm
- the **kit evolution** pattern for growing commands over time

This edition removes enterprise orchestration assumptions.
It is meant for one person, one machine, and durable personal context.
